把日子放到主畫面

盼日的日子做好之後，放上主畫面，每天一打開手機就看得到。四個步驟，一分鐘。

1 / 3

放到主畫面

  1. 在主畫面空白處長按，直到圖示開始晃動
  2. 點左上角的「編輯」→「加入小工具」
  3. 搜尋「盼日」
  4. 左右滑選大小和樣式，按「加入小工具」

2 / 3

選要顯示哪個日子

  • 放好之後長按小工具 →「編輯小工具」，選日子和作品（iOS 17 起）。
  • 更早的系統會自動顯示最近的日子。
  • 小工具每天午夜自動換天數；在盼日裡改了資料，小工具也會跟著更新。

3 / 3

放到鎖定畫面

  1. 在鎖定畫面長按，點「自訂」→「鎖定畫面」
  2. 點時間下方的小工具區
  3. 找到「盼日」，選長方形、圓形或一行字（iOS 16 起）

其他放法

  • 月曆小工具：中尺寸，可以看整個月，或今天加這一週。
  • 全螢幕顯示：打開一個日子按「全螢幕顯示」，把舊 iPad 或 iPhone 當倒數相框。
