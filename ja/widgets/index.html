ホーム画面にカウントダウンや記念日を表示する

日付を登録したら、ホーム画面にウィジェットを置いておくと、スマホを開くたびに確認できます。追加は4ステップで、1分ほどです。

1 / 3

ホーム画面に追加する

  1. ホーム画面の何もないところを、アイコンが揺れ始めるまでタッチしたままにします。
  2. 左上の「編集」をタップし、「ウィジェットを追加」をタップします。
  3. 「Pandays」を検索します。
  4. 左右にスワイプしてサイズとスタイルを選び、「ウィジェットを追加」をタップします。

2 / 3

表示する日付を選ぶ

  • ウィジェットをタッチしたままにして「ウィジェットを編集」をタップし、表示する日付とイラストを選びます（iOS 17以降）。
  • それより前のバージョンでは、登録した日付のうち、今日にいちばん近いものが自動で表示されます。
  • ウィジェットは毎日午前0時に更新されます。Pandaysで内容を変更したときも、すぐに表示に反映されます。

3 / 3

ロック画面に追加する

  1. ロック画面をタッチしたままにし、「カスタマイズ」、「ロック画面」の順にタップします。
  2. 時刻の下にあるウィジェット欄をタップします。
  3. Pandaysを探し、長方形、円形、または1行のタイプを選びます（iOS 16以降）。

カレンダーとフルスクリーンで表示する

  • カレンダーウィジェット：中サイズで、ひと月分のカレンダー、または今日と今週の日付を表示できます。
  • フルスクリーン表示：登録した日付を開き、「全画面表示」をタップします。古いiPadやiPhoneを、イラスト付きのカウントダウンを飾るフォトフレームのように使えます。

まだ日付を登録していない方は、まずAIでオリジナルのイラストを作る方法をご覧ください。
