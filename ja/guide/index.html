AIで自分のイラストを作る

Pandaysでは、スタイルごとに私たちが実際に試したプロンプトを用意しています。プロンプトをコピーしてChatGPTやGeminiに貼り付け、写真を添えます。できたイラストをPandaysに取り込むと、自分だけのウィジェットにできます。所要時間は約5分で、絵を描く技術は必要ありません。

用意するもの

  • PandaysをインストールしたiPhoneまたはiPad。
  • ChatGPTまたはGemini（アプリでもWeb版でも使えます）。無料プランでも画像を作れますが、1日に作れる枚数には上限があります。
  • ペット、自分、ふたりで写った写真、お気に入りの小物など、描きたいものがはっきり写っている写真。写真を添えず、文章で説明することもできます。

作れるイラスト

スタイルは2種類です。ステッカーセットでは、8つのポーズと手描きの数字をPandaysが自動で切り分けます。1枚絵は切り分けず、ウィジェット全体に表示します。

1枚絵の例：2人が写った写真から

1. Pandaysでプロンプトをコピーする

  1. 「つくる」を開き、好きなスタイルを選んで「このスタイルで作品をつくる」をタップします。
  2. 「主役はだれ？」で、ペット、自分、カップル、お気に入りのもの、家族の中から選びます。
  3. ページには、そのプロンプトで実際に生成した画像が表示されます。気に入ったら「プロンプトをコピー」をタップします。プロンプトは英語ですが、翻訳せずにそのまま貼り付けて使えます。
  4. 「ChatGPT を開く」か「Gemini を開く」をタップします。

2a. ChatGPTで描く

  1. 新しいチャットを開きます。
  2. 入力欄の横にある「+」をタップし、描きたいものの写真を添付します。写真はなくてもかまいません。
  3. 入力欄をタッチしたまま押さえ、コピーしたプロンプトを貼り付けて送信します。
  4. 画像ができるまで1〜2分待ちます。先に質問が返ってきたら、「そのまま描いてください」と返信します。
  5. 画像を開き、共有先に「Pandays」を選ぶか、「写真」アプリに保存します。

2b. Geminiで描く

  1. 新しいチャットを開きます。
  2. 入力欄の横にある「+」をタップし、描きたいものの写真を添付します。写真はなくてもかまいません。
  3. プロンプトを貼り付けて送信します。文章だけが返ってきたら、「1枚の画像にしてください」と返信します。
  4. 画像を開いてダウンロードし、「写真」アプリに保存するか、共有先に「Pandays」を選びます。

3. 画像をPandaysに取り込む

  1. 画像をPandaysに共有した場合は、Pandaysを開くと、どの作品を作るか選ぶ画面が表示されます。
  2. 「写真」アプリに保存した場合は、先ほどのページに戻って「セット画像を取り込む」をタップし、画像を選びます。1枚絵のスタイルでは「絵を戻す」をタップします。
  3. ステッカーセットは、8枚のステッカーと0から9までの数字に自動で切り分けられます。うまく切り分けられなかったものは、タップすると取り除けます。

4. ウィジェットの見た目を調整する

保存すると編集画面が開きます。プレビュー上で画像をドラッグして位置を調整し、2本指で拡大・縮小できます。レイアウトや数字のスタイル、色も変えられます。あとから変更したいときは、「つくる」で作品の「編集」をタップします。

ステッカーセットの画像で確認すること

  1. 背景が真っ白な正方形の画像1枚です。
  2. 1段目：ひょっこり顔を出す上半身のポーズが4つ。下端はまっすぐです。
  3. 2段目：全身のポーズが4つあります。
  4. 3段目：手描きの数字が10個、左から右に0から9の順に並んでいます。
  5. ほかの文字やタイトル、透かしは入っていません。

思ったとおりの画像にならないとき

同じチャットで、直してほしいところを伝えて描き直してもらいます。たいていは1回で直ります。

数字が抜けている、欠けている、または順番が違う

「一番下の段に、0から9までの数字を左から右に10個並べて描き直してください」と返信します。それでもPandaysが10個の数字を切り出せない場合は、フォントを使って日数を表示します。

背景が白くない、または格子模様や影がある

「背景を真っ白にして、影を入れずに描き直してください」と返信します。背景が真っ白だと、輪郭に沿ってきれいに切り出せます。

画像に文字やタイトルが入っている

「画像に文字を一切入れずに描き直してください」と返信します。

8つのポーズが同じキャラクターに見えない

「8つとも同じキャラクターです。顔、色、服をそろえて描き直してください」と返信します。

うちのペットに似ていない

明るい場所で撮った、ペットがはっきり大きく写っている写真を使ってみてください。プロンプトの末尾に、毛の色や模様などの特徴を書き足す方法もあります。

画像が何枚かに分かれている

「全部を1枚の画像にまとめてください」と返信します。Pandaysに取り込むには、すべてが1枚に収まっている必要があります。

画像を作ってくれない、または人物の写真を使えない

写真を添えずに、プロンプトの末尾に描きたいものの特徴を文章で書くか、もう一方のAIを試してください。

今日の上限に達したと表示される

無料プランでは、1日に作れる画像の枚数に上限があります。翌日にもう一度試すか、もう一方のAIを使ってください。

写真とプロンプトは、ご自身でChatGPTまたはGeminiに送信します。送信した内容は、各サービスのルールに従って取り扱われます。私たちが写真を受け取ることはなく、Pandaysが私たちのもとにデータをアップロードすることもありません。

うまくいかないときは、サポートページをご覧いただくか、お問い合わせください。サポート
