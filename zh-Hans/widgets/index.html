在主屏幕上显示你记录的日子

在盼日里设好日子后，把它添加到主屏幕，每次打开手机都能看到。四步，一分钟。

1 / 3

添加到主屏幕

  1. 按住主屏幕上的空白处，直到图标开始抖动
  2. 轻点左上角的“编辑”，再轻点“添加小组件”
  3. 搜索“盼日”
  4. 轻扫以选择尺寸和样式，再轻点“添加小组件”

2 / 3

选择要显示的日子

  • 按住小组件，轻点“编辑小组件”，然后选择要显示的日子和作品（iOS 17 及以上版本）。
  • 在较早的系统版本上，小组件会自动显示离今天最近的日子。
  • 小组件会在午夜更新。你在盼日里修改内容后，小组件也会立即更新。

3 / 3

添加到锁屏

  1. 按住锁定屏幕，轻点“自定”，再轻点“锁定屏幕”
  2. 轻点时间下方的小组件区域
  3. 找到盼日，选择矩形、圆形或单行样式（iOS 16 及以上版本）

其他显示方式

  • 日历小组件：中号，可以显示整月日历，也可以显示当天和本周的日期。
  • 全屏显示：打开一个日子，轻点“全屏幕显示”，就能把旧 iPad 或 iPhone 当作倒数相框。
