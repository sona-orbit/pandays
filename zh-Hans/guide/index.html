用 AI 画自己的作品

盼日里每种风格的提示词，我们都实际试过。复制提示词，贴到 ChatGPT 或 Gemini，再附上一张照片。画好后，把图导入盼日，就能做成你自己的小组件。整个过程大约五分钟，不需要会画画。

你需要准备什么

  • 在 iPhone 或 iPad 上安装盼日。
  • ChatGPT 或 Gemini，用 App 或网页版都可以。免费版也能画图，只是每天能画的张数有限。
  • 一张能看清主角的照片。可以是宠物、你自己、你们两个人，或一件喜欢的小物件。没有照片也可以用文字描述。

可以画成什么样

盼日有两种风格：贴纸套装包含 8 个姿势和一组手绘数字，盼日会自动切分；单图则直接铺满小组件，不用切分。

贴纸示例：用一张猫的照片

单幅插画示例：用一张双人照

1. 在盼日里复制提示词

  1. 打开“创作”，选一个喜欢的风格，轻点“用这个风格做我的作品”。
  2. 在“主角是谁？”里选一个：宠物、你自己、情侣、喜欢的东西或家人。
  3. 页面会先展示这段提示词实际画出来的效果。如果你喜欢，就轻点“拷贝提示词”。提示词是英文，直接粘贴就行，不用翻译。
  4. 轻点“开 ChatGPT”或“开 Gemini”。

2a. 用 ChatGPT 画图

  1. 新建一个对话。
  2. 轻点输入框旁的“+”，添加一张主角的照片。不加也可以。
  3. 按住输入框，粘贴刚复制的提示词，然后发送。
  4. 等一两分钟，看看图画好了没有。如果它先问你问题，回一句“请直接画”。
  5. 打开图片，分享到“盼日”，或者存到相册。

2b. 用 Gemini 画图

  1. 新建一个对话。
  2. 轻点输入框旁的“+”，添加一张主角的照片。不加也可以。
  3. 粘贴提示词并发送。如果它只回复了文字，就回一句“请画成一张图”。
  4. 打开图片，下载到相册，或者分享到“盼日”。

3. 把图片导入盼日

  1. 如果你把图片分享到盼日，打开盼日后，App 会让你选要做成哪个作品。
  2. 如果你把图存到了相册，就回到刚才的页面，轻点“传整套图回来”。如果选的是单图风格，就轻点“把图传回来”，然后选中那张图。
  3. 盼日会自动切出 8 张贴纸和 0 到 9 的数字。哪张没切好，轻点一下就能去掉。

4. 调整小组件的样式

保存后会打开编辑器。你可以在预览里拖动图片，用双指缩放，也可以换布局、数字样式和颜色。以后想再改，回到“创作”，轻点作品上的“编辑”。

贴纸套装的图片应该是什么样

  1. 整套内容都在一张正方形的图里，背景是纯白色。
  2. 第 1 排：四个探出半身的姿势，底边要平。
  3. 第 2 排：四个全身姿势。
  4. 第 3 排：十个手绘数字，从左到右是 0 到 9。
  5. 图上没有其他文字、标题或水印。

画得不对怎么办

在同一个对话里回复，请它重画。通常重画一次就够了。

数字没画、没画全，或者顺序不对

回一句“最下面一排要有十个数字，从左到右是 0 到 9。请重画。”如果盼日还是切不出十个数字，也会用字体显示天数。

背景不是白色，或者有网格、阴影

回一句“请重画，背景用纯白色，不要加阴影。”纯白背景切出来最干净。

图上多了文字或标题

回一句“请重画，图上不要加任何文字。”

八个姿势看起来不像同一个角色

回一句“请重画。八个姿势都要画同一个角色，脸、颜色和衣服都要一致。”

画得不像我的宠物

换一张光线好、主角占画面大一些的清晰照片，或者在提示词末尾补一句，描述它的毛色或花纹等特征。

画成了几张分开的图

回一句“请把所有内容画在同一张图里。”盼日需要一张完整的图。

它不肯画，或者不肯用人物照片

不附照片，在提示词末尾用文字描述主角，或者换另一个 AI 试试。

提示今天的次数用完了

免费版每天能画的张数有限。你可以明天再试，或者换另一个 AI。

照片和提示词由你直接发给 ChatGPT 或 Gemini，按所用服务自己的规则处理。我们不会收到你的照片，盼日也不会把任何内容上传给我们。
