# Pandays

Website for **Pandays**, a countdown and anniversary app for iPhone and iPad with widgets for the Home Screen,
Lock Screen and Apple Watch. It comes with 21 illustration styles, and you can turn a photo into your own sticker set
with ChatGPT or Gemini and use it on your widgets.

Served by GitHub Pages at https://sona-orbit.github.io/pandays/

- Home, privacy and support pages in nine languages: English, 繁體中文, 简体中文, 日本語, 한국어, Español, Deutsch, Français, Português (Brasil)
- Static HTML and CSS, no build step on this repository
- Every widget picture on the site is drawn by the app's own widget code
