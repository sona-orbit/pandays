AI로 나만의 작품 그리기

Pandays의 각 스타일에는 저희가 직접 써 본 프롬프트가 있어요. 프롬프트를 복사해 ChatGPT나 Gemini에 붙여넣고 사진을 첨부해요. 완성된 그림을 Pandays로 가져오면 나만의 위젯을 만들 수 있어요. 그림을 그릴 줄 몰라도 되고, 5분 정도 걸려요.

준비물

  • iPhone이나 iPad에 설치한 Pandays가 필요해요.
  • ChatGPT나 Gemini가 필요해요. 앱이나 웹사이트 모두 괜찮아요. 무료 플랜에서도 그림을 만들 수 있지만 하루에 만들 수 있는 장수는 제한돼요.
  • 주인공이 잘 보이는 사진을 준비해요. 반려동물, 내 모습, 두 사람이 함께 찍은 사진, 아끼는 소품 사진 모두 괜찮아요. 사진 없이 글로 설명해도 돼요.

만들 수 있는 그림

스티커 세트와 한 장짜리 그림 중에서 고를 수 있어요. 스티커 세트는 8가지 포즈와 손으로 그린 숫자로 구성되며, Pandays가 각각 잘라 줘요. 한 장짜리 그림은 자르지 않고 위젯 전체를 채워요.

스티커 세트: 고양이 사진으로 만들어요

한 장짜리 그림: 두 사람이 나온 사진으로 만들어요

1. Pandays에서 프롬프트 복사하기

  1. ‘만들기’에서 마음에 드는 스타일을 고르고 ‘이 스타일로 내 작품 만들기’을 탭해요.
  2. ‘주인공은 누구예요?’라는 질문에 답해요. 반려동물, 나, 커플, 좋아하는 물건, 가족 중에서 골라요.
  3. 이 프롬프트로 실제로 그린 그림이 먼저 보여요. 마음에 들면 ‘프롬프트 복사’를 탭해요. 프롬프트는 영어로 되어 있으니 번역하지 말고 그대로 붙여넣어요.
  4. ‘ChatGPT 열기’ 또는 ‘Gemini 열기’를 탭해요.

2a. ChatGPT로 그리기

  1. 새 채팅을 시작해요.
  2. 메시지 입력란 옆의 ‘+’를 탭해 주인공 사진을 첨부해요. 사진을 첨부하지 않아도 돼요.
  3. 메시지 입력란을 길게 터치한 다음 복사한 프롬프트를 붙여넣고 보내요.
  4. 그림이 나올 때까지 1~2분 정도 기다려요. 먼저 질문을 하면 ‘그냥 그려 주세요’라고 답해요.
  5. 그림을 열고 공유 메뉴에서 ‘Pandays’를 선택하거나 사진 앱에 저장해요.

2b. Gemini로 그리기

  1. 새 채팅을 시작해요.
  2. 메시지 입력란 옆의 ‘+’를 탭해 주인공 사진을 첨부해요. 사진을 첨부하지 않아도 돼요.
  3. 프롬프트를 붙여넣고 보내요. 글로만 답하면 ‘그림 한 장으로 그려 주세요’라고 답해요.
  4. 그림을 열고 다운로드하거나 공유해요. 사진 앱에 저장하거나 공유 메뉴에서 ‘Pandays’를 선택해요.

3. 그림을 Pandays로 가져오기

  1. Pandays로 그림을 공유했다면 앱을 열어요. 어떤 작품으로 만들지 물어봐요.
  2. 사진 앱에 저장했다면 아까 보던 페이지로 돌아가 ‘세트 그림 가져오기’를 탭한 뒤 그림을 선택해요. 한 장짜리 그림 스타일이라면 ‘그림 가져오기’를 탭해요.
  3. 스티커 세트는 스티커 8개와 0부터 9까지의 숫자로 자동으로 잘려요. 잘못 잘린 조각은 탭해서 제외할 수 있어요.

4. 위젯 모양 조정하기

저장하면 편집 화면이 열려요. 미리보기에서 그림을 드래그하거나 두 손가락으로 확대·축소해 위치와 크기를 맞추고, 배치와 숫자 모양, 색상을 바꿀 수 있어요. 나중에 다시 바꾸려면 ‘만들기’에서 해당 작품의 ‘편집’을 탭해요.

스티커 세트 그림 확인하기

  1. 배경이 완전히 흰색인 정사각형 그림 한 장이에요.
  2. 1번째 줄에는 고개를 빼꼼 내민 상반신 포즈가 4개 있어요. 각 포즈의 아래쪽은 일자로 잘려 있어요.
  3. 2번째 줄에는 전신 포즈가 4개 있어요.
  4. 3번째 줄에는 손으로 그린 숫자 10개가 왼쪽부터 0부터 9까지 순서대로 있어요.
  5. 다른 글자나 제목, 워터마크는 없어요.

그림이 원하는 대로 나오지 않을 때

같은 채팅에서 다시 그려 달라고 해 보세요. 보통 한 번이면 돼요.

숫자가 빠졌거나 덜 그려졌거나 순서가 달라요

‘맨 아래 줄에 숫자 10개가 있어야 해요. 왼쪽부터 0부터 9까지 순서대로 넣어서 다시 그려 주세요’라고 답해요. 그래도 Pandays에서 숫자 10개를 모두 잘라 내지 못하면, 대신 글꼴로 날짜까지의 일수를 표시해요.

배경이 흰색이 아니거나 격자나 그림자가 있어요

‘배경을 아무 무늬 없는 흰색으로 바꾸고 그림자 없이 다시 그려 주세요’라고 답해요. 흰 배경에서 가장 깔끔하게 잘려요.

그림에 글자나 제목이 들어갔어요

‘그림에 글자를 하나도 넣지 말고 다시 그려 주세요’라고 답해요.

8가지 포즈가 같은 캐릭터처럼 보이지 않아요

‘8가지 포즈 모두 같은 캐릭터예요. 얼굴과 색, 옷을 같게 해서 다시 그려 주세요’라고 답해요.

우리 반려동물과 닮지 않았어요

반려동물이 너무 작게 나오지 않고 밝고 선명하게 찍힌 사진을 써 보세요. 프롬프트 끝에 털 색이나 무늬 같은 특징을 한 줄 덧붙여도 돼요.

그림이 여러 장으로 나뉘어 나왔어요

‘전부 한 장에 그려 주세요’라고 답해요. Pandays에서는 전체가 담긴 그림 한 장이 필요해요.

그림을 그려 주지 않거나 사람 사진을 쓸 수 없다고 해요

사진을 첨부하지 말고 프롬프트 뒤에 주인공을 글로 설명해 보세요. 다른 AI를 써 봐도 돼요.

오늘 만들 수 있는 그림 수를 다 채웠다고 해요

무료 플랜에서는 하루에 그림을 몇 장만 만들 수 있어요. 내일 다시 시도하거나 다른 AI를 써 보세요.

사진과 프롬프트는 사용자가 ChatGPT나 Gemini에 직접 보내고, 각 서비스가 자체 정책에 따라 처리해요. Pandays는 사진을 수집하지 않으며, 저희 쪽으로 어떤 것도 업로드하지 않아요.

그래도 잘 안 되면 지원 페이지를 확인하거나 저희에게 문의해 주세요.지원
